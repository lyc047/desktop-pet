# Photopea 套索导引图

这些 SVG 与 `pet.png` 使用相同的 1086 × 1448 画布。将其中一张拖入 Photopea，并放在最顶层；导入时保持原尺寸和原位置，边界就会与角色对齐。

导引图只标记“可见区域的推荐套索边缘”。关节和前后遮挡位置需保留 2–4 px 重叠；它们不是最终可动部件的精确透明边缘。

## 使用顺序

1. 打开 `guide_01_core_layers.svg`：先做头部、前发、后发、身体。
2. 打开 `guide_02_limbs_braids.svg`：第二轮做手臂、辫子、双腿。
3. 打开 `guide_03_face_parts.svg`：最后做眼睛、瞳孔、眼睑和嘴。

每次只导入一张导引图，完成当前轮次后隐藏或删除导引图层。不要把 SVG 导引图导出为角色 PNG。

## 特别注意

- `guide_03_face_parts.svg` 只用于规划面部。要实现眨眼，`head_base.png` 最终必须补成“没有原始睁眼和嘴”的脸部底图；不要在第一轮强行完成这一步。
- 身体和头发遮挡的部分在原图中没有像素，需要后续补全，不能靠套索凭空获得。
- `ground_shadow.png` 不需要在 Photopea 套索；将由程序在下一步生成。
