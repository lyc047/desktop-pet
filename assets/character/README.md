# 桌宠角色资产目录

这里存放从 `pet.png` 拆出的可动角色资产。第一阶段不替换根目录中的 `pet.png`、`happy_*.png` 或 `walk*.png`；现有桌宠可继续正常运行。

## 使用顺序

1. 在 Photopea 打开根目录的 `pet.png`。
2. 依照 `character_spec.md` 拆分图层并补全遮挡区域。
3. 按 `layers/manifest.json` 的名称导出透明 PNG。
4. 将文件放入 `layers/` 对应位置。
5. 让 Agent 执行合成、边缘、锚点和程序接入检查。

## 约束

- 不要覆盖 `pet.png`。
- 不要为单个动作重新生成整个角色；优先只更新局部图层。
- 图层命名必须与清单一致，左右以角色自身视角命名。
- 首次导出建议保留完整 1086 × 1448 画布，避免错位；稳定后才可裁掉透明边缘。
