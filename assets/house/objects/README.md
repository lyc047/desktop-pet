# 小屋独立物件清单（V2）

底图：`../room_base_master_v1.png`。底图只包含房屋结构、固定家具和固定阴影；以下物件均由 `house_scene_v2.py` 独立绘制或加载，拥有自己的动画状态。

## 窗边

- 左窗、右窗：分别开合，互不影响。
- 左窗帘、右窗帘：分别收拢或展开。
- 窗边便签：轻轻摆动后打开桌宠便签。
- 吊兰、窗台植物：按固定点自然摇摆并逐渐停止。

## 墙面与柜子

- 两幅挂画：受力后绕挂点摆动并回正。
- 挂钟：点击后开启或停止钟摆。
- 柜中书：依次倾斜再复位。
- 收音机：点击开关；开启后音符独立播放。
- 后柜抽屉：沿纵深方向拉出或推回。
- 玩具车：在柜面安全范围内来回移动。

## 沙发区域

- 台灯：点击开灯或关灯，光晕保持状态。
- 边桌抽屉：拉出或推回。
- 两只靠垫：分别受压、回弹。
- 沙发：轻微下陷后让桌宠回到桌面睡眠状态。

## 桌面与画架

- 茶壶与杯子：六帧抬壶、倾斜、倒水、复位、冒热气动作。
- 书：纸页从右向左翻动。
- 数字华容道：轻抬反馈后打开可玩的 4×4 游戏。
- 画布：落下一笔后打开绘画窗口。
- 画笔罐：受碰后绕底部轻摇。

## 出入口与收纳

- 收纳箱：箱盖打开后进入桌宠收纳目录，再点一次可合上。
- 房门：门板向门轴方向打开，然后仅离开小屋并恢复桌宠，不关闭应用。

所有物件状态都存放在独立字典项中，同一时间可并行动画，不使用从完整房间成图裁切的矩形补丁。
