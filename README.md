# 桌面宠物 Desktop Pet

一个基于 **Python + PySide6（Qt 6）** 开发的 Windows 桌面宠物。它不再只是循环播放一张贴图，而是拥有待机生命感、自然眨眼、鼠标互动、拖拽反馈、睡眠与醒来、情绪状态、屏幕边缘探头、实用收纳箱和可自定义台词。

角色资产采用 AI 辅助生成，再经过对齐、分层、局部替换和逐帧稳定处理；程序使用无边框透明窗口显示，不占用任务栏。

## 当前版本亮点

- **有生命感的待机**：呼吸、轻微摆动、随机眨眼和脚下接触阴影。
- **鼠标感知**：鼠标靠近并停留后进入好奇状态，在一定范围内持续看向鼠标；离远后才退出。
- **情绪状态**：好奇、被摸头、惊讶、委屈、无聊、不满、困倦和头晕等表情自然接入统一状态机。
- **持续摸头**：长按触发摸头，鼠标不松开便持续保持摸头表情，松开后再自然恢复。
- **拖拽与落地**：提起时切换悬挂姿态，根据拖动方向稳定摆向一侧；松开后带压缩和回弹。
- **摇晃头晕**：快速左右摇晃后进入头晕眼花状态，并显示对应台词。
- **睡眠系统**：长时间无操作后先困倦再睡觉；睡眠中有呼吸循环和随机蹭枕头动作。
- **睡眠互动**：睡着时单击会蹭枕头并说梦话；双击或右键“停止睡觉”才会播放睡眼惺忪、打哈欠和醒来动画。
- **屏幕边缘互动**：靠近左右边缘才会吸附，支持扒边和右侧探头，两个方向均有独立自然眨眼。
- **灵动气泡**：圆角气泡、描边和箭头会跟随桌宠；不同状态之间有台词间隔保护，不会互相抢话。
- **单实例运行**：重复启动不会生成第二只桌宠，现有桌宠会提示“一个我就可以啦！”。

## 文件与内容收纳

可以把内容直接拖到桌宠身上，程序会在后台自动分类，避免界面卡顿：

| 拖入内容 | 保存位置 |
|---|---|
| 普通文件 | 收纳箱根目录 |
| 普通文字 | 追加到 `桌宠便签.txt`，自动记录时间 |
| 网页链接 | 追加到 `链接收藏.txt`，自动记录时间 |
| 本地图片或可拖出的网页图片 | 保存到 `图片收藏/` |

同名文件不会覆盖，而是自动增加序号。默认收纳位置为 Windows“文档/桌宠收纳箱”，也可以在设置中修改。右键桌宠的“收纳箱”子菜单可以分别打开全部内容、便签、链接和图片收藏。

## 设置界面

右键桌宠选择“设置…”即可修改。常用项目直接显示，较少使用的行为参数放在“高级设置”中，避免界面过于繁杂。

### 常用设置

- 桌宠大小
- 气泡停留时间
- 是否始终置顶
- 文件收纳箱位置

### 台词设置

每个触发情境都可以单独编辑台词，每行一句，触发时随机选择。支持普通说话、连续点击、摸头、惊讶、委屈、无聊、困倦、梦话、醒来、头晕、贴边和文件/文字/链接/图片收纳等分类。

### 高级设置

- 好奇、无聊、自动睡眠和摇晃头晕开关
- 好奇触发时间与保持范围
- 长按摸头时间
- 无聊和自动睡眠等待时间
- 连续点击不满阈值
- 摇晃触发灵敏度
- 两段台词间隔与动作结束保护时间

设置保存在用户的 `%APPDATA%/DesktopPet/settings.json`，不会污染项目目录；旧版本设置缺少的新字段会自动补齐。

## 操作说明

| 操作 | 效果 |
|---|---|
| 单击 | 轻微按压与回弹 |
| 连续点击 | 逐步表现委屈或不满 |
| 长按不移动 | 进入摸头状态，按住多久就保持多久 |
| 左键拖拽 | 提起并移动桌宠，松开后落地 |
| 快速左右摇晃 | 触发头晕状态 |
| 拖到屏幕左右边缘 | 靠近边缘时吸附并切换边缘姿态 |
| 睡眠时单击 | 播放蹭枕头动作并说梦话 |
| 睡眠时双击 | 播放完整醒来动画 |
| 清醒时双击 | 惊讶表情 |
| 拖入文件、文字、链接或图片 | 自动分类保存到收纳箱 |
| 右键 | 动画、表情预览、收纳箱、设置和退出 |

## 快速开始

### 环境要求

- Windows 10 / 11
- Python 3.9+（建议使用 3.10 或更新版本）

### 源码运行

```bash
pip install -r requirements.txt
python main.py
```

Windows 用户也可以双击 `启动桌宠.bat`。

## 下载独立版本

已经发布的 Windows 单文件版本可从 [Releases](https://github.com/lyc047/desktop-pet/releases/latest) 下载，无需安装 Python。

独立程序没有商业数字签名，Windows SmartScreen 可能在首次运行时提示。Release 说明中提供 SHA-256；可使用以下命令核对：

```bash
certutil -hashfile DesktopPet.exe SHA256
```

## 打包

仓库包含 GitHub Actions 发布流程。推送 `v*` 格式的标签（例如 `v1.1.0`）后，会在 Windows 环境自动打包、计算 SHA-256 并创建 Release。

本地打包示例：

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name DesktopPet \
  --add-data "happy_*.png;." \
  --add-data "walk*.png;." \
  --add-data "pet.png;." \
  --add-data "assets;assets" \
  main.py
```

产物位于 `dist/DesktopPet.exe`。

## 实现思路

- 使用固定透明舞台统一不同素材尺寸，避免呼吸、拖拽和换帧时窗口跳动。
- 表情切换借助闭眼帧遮挡五官变化，减少“突然换脸”。
- 睡眠、醒来和蹭枕头素材先进行角色与家具对齐，再作为运行帧使用。
- 拖拽方向采用带阈值的锁定逻辑，低速移动时不会左右抽动。
- 自动行为、动作、台词分别设置保护期，避免刚醒来便立刻触发好奇等冲突。
- 文件收纳在单线程后台任务中完成，同批次顺序处理，避免同名文件竞争。
